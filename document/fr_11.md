# Đặc Tả Cài Đặt Ghi Log Thời Gian Thực Hiện (FR-11)

Tài liệu này đặc tả cơ chế đo lường và ghi nhận thời gian xử lý (Execution Time/Performance Logging) của tất cả các Controller và Service trong hệ thống bằng cách sử dụng Lập trình hướng khía cạnh (AOP - Aspect-Oriented Programming).

---

## 📖 Luồng Nghiệp Vụ & Thiết Kế Kiến Trúc
Tính năng **Ghi log thời gian thực hiện (FR-11)** giúp kiểm soát và giám sát hiệu năng của hệ thống theo thời gian thực (Real-time Performance Monitoring). Thay vì chèn thủ công mã nguồn đo thời gian chạy (System.currentTimeMillis()) vào từng phương thức, chúng ta áp dụng khía cạnh (Aspect) để tự động hóa hoàn toàn quá trình này.

```mermaid
graph TD
    A[Yêu cầu API từ Client] --> B[Controller interceptor / JointPoint]
    B --> C[Ghi nhận thời gian bắt đầu: start]
    C --> D[proceed() thực thi logic nghiệp vụ thực tế]
    D --> E[Ghi nhận thời gian kết thúc: end]
    E --> F[Tính toán thời gian chạy: duration = end - start]
    F --> G[Ghi log: [PERFORMANCE] Class -> Method executed in duration ms]
    G --> H[Trả response về cho Client]
```

## 🛠️ Triển khai mã nguồn (Implementation Detail)

Việc ghi nhận thời gian được định nghĩa tập trung thông qua lớp Aspect **[LoggingAspect.java](file:///d:/IT211/Me/src/main/java/atmin/common/aspect/LoggingAspect.java)** bằng lời khuyên `@Around`:

```java
package atmin.common.aspect;

import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.Around;
import org.aspectj.lang.annotation.Aspect;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;

@Aspect
@Component
@Slf4j
public class LoggingAspect {

    // Pointcut cấu hình bắt toàn bộ các phương thức trong controller và service implementation
    @Around("execution(* atmin.controller..*.*(..)) || execution(* atmin.service.Impl..*.*(..))")
    public Object logExecutionTime(ProceedingJoinPoint joinPoint) throws Throwable {
        long start = System.currentTimeMillis();
        
        // Thực thi phương thức gốc
        Object proceed = joinPoint.proceed();
        
        long executionTime = System.currentTimeMillis() - start;

        // Trích xuất tên lớp và tên phương thức đang chạy
        String className = joinPoint.getSignature().getDeclaringType().getSimpleName();
        String methodName = joinPoint.getSignature().getName();
        
        // Ghi log ra console/file log ở mức độ INFO
        log.info("[PERFORMANCE] {} -> {}() executed in {} ms", className, methodName, executionTime);

        return proceed;
    }
    
    // ... các advice Audit khác (createBooking)
}
```

## 💾 Định Dạng Log & Ví Dụ (Log Format Examples)

Hệ thống ghi nhận thời gian thực thi theo định dạng chuẩn:
```text
[Thời gian hệ thống] INFO [Tên thread] [Tên class aspect] : [PERFORMANCE] [Tên Controller/Service] -> [Tên hàm]() executed in [Số miligiây] ms
```

### Ví dụ thực tế thu được từ console:
1. **Khi thực thi Controller xác thực**:
   ```text
   2026-06-14T22:23:54.498 INFO [Test worker] atmin.common.aspect.LoggingAspect : [PERFORMANCE] AuthController -> login() executed in 45 ms
   ```
2. **Khi thực thi Service nghiệp vụ**:
   ```text
   2026-06-14T22:23:54.492 INFO [Test worker] atmin.common.aspect.LoggingAspect : [PERFORMANCE] AuthService -> login() executed in 38 ms
   ```
3. **Khi lấy thông tin tài khoản admin**:
   ```text
   2026-06-14T22:29:58.489 INFO [Test worker] atmin.common.aspect.LoggingAspect : [PERFORMANCE] AdminController -> getUserById() executed in 12 ms
   ```

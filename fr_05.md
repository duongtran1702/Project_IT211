# Đặc Tả & Chi Tiết Triển Khai: Quản Lý Người Dùng (FR-05)

Tính năng **Quản lý người dùng (FR-05)** đã được triển khai hoàn chỉnh dành cho Quản trị viên (`ROLE_ADMIN`), cung cấp các API để thực hiện CRUD, Tìm kiếm và Phân trang người dùng với cấu trúc dữ liệu phản hồi bọc trong `ApiResponse` chuẩn.

> [!NOTE]
> Đối tượng DTO phản hồi `UserResponse` đã được cập nhật loại bỏ các trường `isEnabled` và `createdAt` nhằm tối giản hóa thông tin theo yêu cầu hệ thống.

---

## 🚀 Tài Liệu Hướng Dẫn Gọi API (API Specification)

### 1. Lấy danh sách người dùng (Tìm kiếm & Phân trang)
*   **Method:** `GET`
*   **Path:** `/api/v1/admin/users`
*   **Access:** `ROLE_ADMIN` (Yêu cầu JWT Token hợp lệ của Admin)
*   **Params:**
    *   `keyword`: Từ khóa tìm kiếm theo username, email hoặc fullName (không bắt buộc, mặc định là rỗng).
    *   `page`: Vị trí trang, bắt đầu từ `0` (mặc định: `0`).
    *   `size`: Số bản ghi mỗi trang (mặc định: `10`).

#### B. Trường hợp lỗi
*   **Chưa xác thực (401 Unauthorized):** (Không đính kèm token hoặc token không hợp lệ)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 401,
      "error": "Unauthorized",
      "message": "Full authentication is required to access this resource",
      "path": "/api/v1/admin/users"
    }
    ```
*   **Không có quyền truy cập (403 Forbidden):** (Truy cập bằng token của vai trò CUSTOMER hoặc MANAGER)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 403,
      "error": "Forbidden",
      "message": "Access Denied",
      "path": "/api/v1/admin/users"
    }
    ```
*   **Lỗi tham số phân trang không hợp lệ (400 Bad Request):** (Truyền tham số `page` hoặc `size` sai kiểu dữ liệu, ví dụ: `page=abc`)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 400,
      "error": "Bad Request",
      "message": "Failed to convert value of type 'java.lang.String' to required type 'int' for parameter 'page' / 'size'",
      "path": "/api/v1/admin/users"
    }
    ```

### 2. Lấy thông tin chi tiết người dùng
*   **Method:** `GET`
*   **Path:** `/api/v1/admin/users/{id}`
*   **Access:** `ROLE_ADMIN`

#### A. Trường hợp thành công (200 OK)
*   **Response (JSON):**
    ```json
    {
      "success": true,
      "message": "User retrieved successfully",
      "data": {
        "id": 1,
        "username": "admin",
        "fullName": "System Administrator",
        "email": "admin@example.com",
        "phoneNumber": "0912345678",
        "roles": [
          "ROLE_ADMIN"
        ]
      }
    }
    ```

#### B. Trường hợp lỗi
*   **Không tìm thấy người dùng (404 Not Found):**
    > [!IMPORTANT]
    > Theo cơ chế của `GlobalExceptionHandler`, khi gặp lỗi `ResourceNotFoundException`, HTTP status trả về của phản hồi là **404 Not Found**, nhưng mã `status` và `error` bên trong cấu trúc JSON body được map là **409 Conflict**.
    
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 409,
      "error": "Conflict",
      "message": "User not found with id: 99",
      "path": "/api/v1/admin/users/99"
    }
    ```
*   **Lỗi Phân Quyền (401 / 403):** Tương tự mục 1.B.

---

### 3. Tạo mới người dùng (Admin tạo tài khoản)
*   **Method:** `POST`
*   **Path:** `/api/v1/admin/users`
*   **Access:** `ROLE_ADMIN`
*   **Body (JSON Request):**
    ```json
    {
      "username": "new_manager",
      "password": "password123",
      "fullName": "Tran Tri Duong",
      "email": "duongtran@example.com",
      "phoneNumber": "0987654321",
      "roleIds": [2]
    }
    ```

#### A. Trường hợp thành công (201 Created)
*   **Response (JSON):**
    ```json
    {
      "success": true,
      "message": "User created successfully",
      "data": {
        "id": 2,
        "username": "new_manager",
        "fullName": "Tran Tri Duong",
        "email": "duongtran@example.com",
        "phoneNumber": "0987654321",
        "roles": [
          "ROLE_MANAGER"
        ]
      }
    }
    ```

#### B. Trường hợp lỗi
*   **Lỗi Validation (400 Bad Request):** (Ví dụ: số điện thoại không đúng 10 số, thiếu full name)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 400,
      "error": "Bad Request",
      "message": "Validation failed",
      "path": "/api/v1/admin/users",
      "errors": {
        "phoneNumber": "Phone number must be exactly 10 numeric digits",
        "fullName": "Full name is required"
      }
    }
    ```
*   **Lỗi Trùng Lặp Thông Tin (409 Conflict):** (Tên đăng nhập hoặc Email đã tồn tại)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 409,
      "error": "Conflict",
      "message": "Username already exists!",
      "path": "/api/v1/admin/users"
    }
    ```

---

### 4. Cập nhật thông tin người dùng
*   **Method:** `PUT`
*   **Path:** `/api/v1/admin/users/{id}`
*   **Access:** `ROLE_ADMIN`
*   **Body (JSON Request):**
    ```json
    {
      "fullName": "Tran Tri Duong Updated",
      "email": "duongtran_new@example.com",
      "phoneNumber": "0987654321",
      "isEnabled": false,
      "roleIds": [2]
    }
    ```

#### A. Trường hợp thành công (200 OK)
*   **Response (JSON):**
    ```json
    {
      "success": true,
      "message": "User updated successfully",
      "data": {
        "id": 2,
        "username": "new_manager",
        "fullName": "Tran Tri Duong Updated",
        "email": "duongtran_new@example.com",
        "phoneNumber": "0987654321",
        "roles": [
          "ROLE_MANAGER"
        ]
      }
    }
    ```

#### B. Trường hợp lỗi
*   **Lỗi Validation (400 Bad Request):** (Ví dụ: Email không hợp lệ)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 400,
      "error": "Bad Request",
      "message": "Validation failed",
      "path": "/api/v1/admin/users/2",
      "errors": {
        "email": "Email should be valid"
      }
    }
    ```
*   **Lỗi Trùng Lặp Email (409 Conflict):** (Cập nhật email trùng với email của tài khoản khác đã có trên hệ thống)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 409,
      "error": "Conflict",
      "message": "Email already exists!",
      "path": "/api/v1/admin/users/2"
    }
    ```
*   **Lỗi Không Tìm Thấy Người Dùng (404 Not Found):** (HTTP Status: 404, Body status: 409)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 409,
      "error": "Conflict",
      "message": "User not found with id: 99",
      "path": "/api/v1/admin/users/99"
    }
    ```

*   **Path:** `/api/v1/admin/users/{id}`
*   **Access:** `ROLE_ADMIN`

#### A. Trường hợp thành công (200 OK)
*   **Response (JSON):**
    ```json

    }
    ```

#### B. Trường hợp lỗi

    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 409,
      "error": "Conflict",
      "message": "User not found with id: 99",

# Đặc Tả & Chi Tiết Triển Khai: Đăng Ký Tài Khoản Người Dùng (FR-04)

Tính năng **Đăng ký tài khoản người dùng (FR-04)** đã được triển khai hoàn chỉnh và sửa đổi các vấn đề bảo mật/mã HTTP theo đúng đặc tả yêu cầu hệ thống (SRS).

---

## 🚀 Tài Liệu Hướng Dẫn Gọi API (API Specification)

### 1. Đăng ký tài khoản (`FR-04`)
*   **Method:** `POST`
*   **Path:** `/api/v1/auth/register`
*   **Access:** `Public` (Không yêu cầu token)
*   **Body (JSON Request):**
    ```json
    {
      "username": "customer_test",
      "password": "password123",
      "fullName": "Nguyen Van A",
      "email": "customer_a@example.com",
      "phoneNumber": "0987654321"
    }
    ```

#### A. Trường hợp thành công (201 Created)
*   **Response (JSON):**
    ```json
    {
      "success": true,
      "message": "User registered successfully!"
    }
    ```

#### B. Trường hợp lỗi
*   **Lỗi Validation (400 Bad Request):** (Ví dụ: Số điện thoại không đủ 10 số hoặc thiếu thông tin)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 400,
      "error": "Bad Request",
      "message": "Validation failed",
      "path": "/api/v1/auth/register",
      "errors": {
        "phoneNumber": "Phone number must be exactly 10 numeric digits"
      }
    }
    ```
*   **Lỗi Trùng Lặp (409 Conflict):** (Tên đăng nhập hoặc Email đã tồn tại)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 409,
      "error": "Conflict",
      "message": "Username already exists!",
      "path": "/api/v1/auth/register"
    }
    ```

---

### 2. Đăng nhập hệ thống (`FR-01`)
*   **Method:** `POST`
*   **Path:** `/api/v1/auth/login`
*   **Access:** `Public`
*   **Body (JSON Request):**
    ```json
    {
      "username": "customer_test",
      "password": "password123"
    }
    ```

#### A. Trường hợp thành công (200 OK)
*   **Response (JSON):**
    ```json
    {
      "success": true,
      "message": "Login successfully!",
      "data": {
        "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiJjdXN0b21lcl90ZXN0IiwiYXV0aG9yaXRpZXMiOlsiUk9MRV9DVVNUT01FUiJdLCJpYXQiOjE3ODEwOTcxMDAsImV4cCI6MTc4MTA5NzcwMH0.signature",
        "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiJjdXN0b21lcl90ZXN0IiwiYXV0aG9yaXRpZXMiOlsiUk9MRV9DVVNUT01FUiJdLCJpYXQiOjE3ODEwOTcxMDAsImV4cCI6MTc4MTEwMDcwMH0.signature"
      }
    }
    ```

#### B. Trường hợp lỗi
*   **Lỗi Validation (400 Bad Request):** (Ví dụ: Thiếu username hoặc password)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 400,
      "error": "Bad Request",
      "message": "Validation failed",
      "path": "/api/v1/auth/login",
      "errors": {
        "username": "Username is required"
      }
    }
    ```
*   **Lỗi Sai Thông Tin (401 Unauthorized):** (Nhập sai mật khẩu hoặc tài khoản không đúng)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 401,
      "error": "Unauthorized",
      "message": "Bad credentials",
      "path": "/api/v1/auth/login"
    }
    ```

### 3. Làm mới Token (`FR-02`)
*   **Method:** `POST`
*   **Path:** `/api/v1/auth/refresh`
*   **Access:** `Public`
*   **Params:** `refreshToken=eyJhbG...`

#### A. Trường hợp thành công (200 OK)
*   **Response (JSON):**
    ```json
    {
      "success": true,
      "message": "Refresh successfully!",
      "data": {
        "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.new_access_token_signature",
        "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.new_refresh_token_signature"
      }
    }
    ```

#### B. Trường hợp lỗi
*   **Lỗi Token Không Hợp Lệ / Hết Hạn (401 Unauthorized):**
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 401,
      "error": "Unauthorized",
      "message": "Refresh token is expired",
      "path": "/api/v1/auth/refresh"
    }
    ```
*   **Lỗi Tấn Công Phát Lại (401 Unauthorized):** (Token đã bị thu hồi trước đó do nghi ngờ bị đánh cắp và dùng lại)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 401,
      "error": "Unauthorized",
      "message": "Refresh token has been revoked due to potential reuse attack",
      "path": "/api/v1/auth/refresh"
    }
    ```
*   **Lỗi Không Tìm Thấy Token Trong Hệ Thống (409 Conflict):** (Do cấu hình `ResourceNotFoundException` trả về Conflict code trong JSON body)
    ```json
    {
      "timestamp": "2026-06-11T05:55:00",
      "status": 409,
      "error": "Conflict",
      "message": "Refresh token not found",
      "path": "/api/v1/auth/refresh"
    }
    ```
